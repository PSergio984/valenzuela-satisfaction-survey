<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public Respondent → API | Untrusted input (answers, started_at) crosses into the system. |
| Admin → Export System | Background jobs process data and store it on the private disk. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | `started_at` payload | mitigate | Validate `started_at` is a valid date and not in the future. |
| T-01-02 | Information Disclosure | Excel Exports | mitigate | Use the `private` disk for storage; ensure only authorized admins can download. |
| T-01-03 | Denial of Service | Export Processing | mitigate | Use Queued Exports (ShouldQueue) to prevent blocking the web server. |
| T-01-04 | Tampering | Pagination/Search Params | mitigate | Use standard Laravel validation and Eloquent parameter binding. |
</threat_model>
